# ⚡ MailBlast Pro

A professional email campaign tool with unlimited sending, random subject/body rotation, file attachments, and real-time delivery logs.

---

## Features

- **Unlimited emails** — send to as many recipients as you need
- **Random subject rotation** — add multiple subjects; one is picked randomly per email
- **Random body rotation** — add multiple message bodies for variety (reduces spam flags)
- **File attachments** — attach PDFs, images, documents (up to 25MB each)
- **HTML or plain text** — toggle HTML mode to send rich emails
- **SMTP presets** — Gmail, Outlook, SendGrid, Mailgun, Amazon SES, Yahoo
- **Real-time log console** — live delivery status with per-email results
- **Configurable delay** — set seconds between emails to avoid throttling
- **Connection test** — verify SMTP before sending

## Deploy to Render (Recommended)

### 1. Push to GitHub

```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/YOUR_USERNAME/mailblast-pro.git
git push -u origin main
```

### 2. Create Render Web Service

1. Go to [render.com](https://render.com) and sign up/login
2. Click **New → Web Service**
3. Connect your GitHub repo
4. Render auto-detects `render.yaml` — settings are pre-configured:
   - **Build Command:** `npm install --prefix backend && npm install --prefix frontend && npm run build --prefix frontend`
   - **Start Command:** `node backend/server.js`
5. Click **Deploy**

Your app will be live at `https://mailblast-pro.onrender.com` (or similar).

## Local Development

### Prerequisites
- Node.js 18+

### Setup

```bash
# Install all dependencies
npm install --prefix backend
npm install --prefix frontend

# Terminal 1: Start backend
npm run dev:backend

# Terminal 2: Start frontend dev server
npm run dev:frontend
```

- Frontend: http://localhost:5173
- Backend API: http://localhost:3001

### Build for production (serves frontend from backend)

```bash
npm run build        # builds frontend into backend/public/
node backend/server.js
# Visit http://localhost:3001
```

## SMTP Settings by Provider

| Provider    | Host                                      | Port | Auth                      |
|-------------|-------------------------------------------|------|---------------------------|
| Gmail       | smtp.gmail.com                            | 587  | App Password (not Gmail PW) |
| Outlook     | smtp-mail.outlook.com                     | 587  | Your password             |
| Yahoo       | smtp.mail.yahoo.com                       | 587  | App Password              |
| SendGrid    | smtp.sendgrid.net                         | 587  | Username: `apikey`, PW: API key |
| Mailgun     | smtp.mailgun.org                          | 587  | SMTP credentials from dashboard |
| Amazon SES  | email-smtp.us-east-1.amazonaws.com       | 587  | SMTP credentials from AWS |
| Custom      | mail.yourdomain.com                       | 587  | cPanel SMTP credentials   |

### Gmail App Password Setup
1. Google Account → Security → 2-Step Verification (enable)
2. Search "App passwords" → Create one for "Mail"
3. Use the 16-character password in MailBlast

## Anti-Spam Tips

- **Use 3+ subject variants** — randomization reduces pattern detection
- **Use 3+ body variants** — vary wording, not just small changes
- **Set 2–5s delay** between emails
- **Configure SPF/DKIM** records on your sending domain
- **Use reputable SMTP** — SendGrid, Mailgun, or Amazon SES for high volume
- **Warm up new domains** — start with small batches, increase gradually
